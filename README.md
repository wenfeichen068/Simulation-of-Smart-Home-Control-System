# 智能家居控制系统 (Simulation_of_Smart_Home_Control_System)

一个基于Python Tkinter的智能家居控制系统模拟程序，支持多用户权限管理、设备控制、自动化规则和设备共享功能。

## 功能特性

### 🔐 用户认证与权限管理
- 多用户支持（管理员/普通用户）
- 基于角色的权限控制
- 密码SHA-256加密存储

### 🏠 设备类型支持
- **照明设备 (Light)**: 开关控制、亮度调节
- **空调 (AirConditioner)**: 开关控制、温度设置
- **窗帘 (Curtain)**: 开合度控制
- **摄像头 (Camera)**: 开关控制、角度调节
- **通用设备**: 基础开关功能

### 🔒 权限系统
- **管理员**: 完全控制所有设备
- **设备所有者**: 完全控制自己的设备，可共享给其他用户
- **被共享用户**: 可控制设备但无法再次共享或删除
- **访客**: 仅查看权限范围内的设备

### ⚡ 自动化功能
- **定时任务**: 按指定时间执行设备操作
- **智能规则**: 基于传感器数据自动触发设备操作
  - 示例：高温自动开启空调

### 🔐 数据安全
- 可选数据加密存储
- 操作日志记录
- 安全的权限验证机制

## 安装与运行

### 系统要求
- Python 3.6+
- 无需额外依赖（使用标准库）

### 运行步骤
1. 下载 `smart_home5.py` 文件
2. 在终端中运行：
   ```bash
   python smart_home5.py
   ```

## 使用说明

### 默认账户
- **管理员**: 
  - 用户名: `admin`
  - 密码: `admin123`
- **普通用户**: 
  - 用户名: `user1` / `user2`
  - 密码: `123456`

### 主要操作

#### 设备管理
- **添加设备**: 点击"添加设备"按钮，输入设备ID、名称和类型
- **删除设备**: 选中设备后点击"删除选中"（仅所有者或管理员）
- **控制设备**: 双击设备打开控制面板

#### 设备控制
- **电源开关**: 打开/关闭设备
- **属性调节**: 根据不同设备类型调节亮度、温度、开合度或角度
- **设备共享**: 所有者可将设备共享给其他用户

#### 自动化功能
- **定时任务**: 设置设备在指定时间执行操作
- **传感器模拟**: 模拟环境数据触发自动化规则

## 文件说明

- `smart_home5.py`: 主程序文件
- `data.json`: 用户和设备数据存储文件
- `logs.txt`: 系统操作日志文件

## 技术架构

### 核心模块
1. **SecurityUtils**: 安全加密工具类
2. **Device类层次**: 设备基类和具体设备类型
3. **BackendSystem**: 后端系统核心，包含权限逻辑和数据处理
4. **SmartHomeGUI**: 图形用户界面

### 权限验证流程
1. 用户登录时确定角色
2. 设备操作前进行权限检查
3. 根据角色和设备关系决定操作权限

## 开发特点

- 面向对象设计，易于扩展新设备类型
- 完整的权限验证机制
- 线程安全的定时任务调度
- 模块化架构，便于维护

## 注意事项

- 首次运行会自动创建默认用户和设备
- 启用加密存储后数据文件将以Base64编码保存
- 定时任务在后台线程中运行，每分钟检查一次
- 所有操作都会被记录到日志文件中
